# Selecting a model for the actual deliverable

Read for model comparisons or when the required output could be produced through several operations. Model families below are discovery terms, not guaranteed current versions, prices, rankings, or benefits.

## Match the operation before comparing quality

| Required result | Capability to discover | Candidate families or tools to inspect |
| --- | --- | --- |
| Precise composition or a targeted image edit | Image references, masks, instruction fidelity, output sizing | GPT Image, Nano Banana Pro, FLUX/Kontext, Seedream |
| Many variants of an approved subject | Multiple references, identity/style preservation, regional editing | Nano Banana, Seedream, reference-capable image models |
| Scalable icons or illustrations | Native SVG/vector output and palette controls | Recraft vector modes, Ideogram Vector, vector-capable GPT Image |
| Isolated props for compositing | Native transparent output or background removal | Transparent-capable image models and removal tools |
| Repeating a visual style | Saved-style workflow or explicit style-reference inputs | Recraft Styles or reference-capable alternatives |
| A recurring person or character | Identity references or reusable character elements | Soul, character builders, reference-capable image/video models |
| A transition with specified endpoints | First/last frame support | Seedance, Wan, Kling, Gemini Omni where the selected version supports it |
| Several controlled moments in a shot | Ordered intermediate keyframes | Multi-keyframe video models such as supported Kling versions |
| Copying a performance or camera movement | Driving video plus subject references | Genjutsu motion transfer, motion-control tools |
| Replacing a subject in existing footage | Source-video editing and replacement references | Genjutsu replacement or a supported video-edit model |
| A new finished narrative shot | Video generation, reference control, desired sound and duration | Seedance, Kling, Veo, MiniMax, Wan or alternatives in the current catalog |
| Voice, dialogue, music, or effects | Correct audio task, language, voice selection, timing | Relevant speech/music/effects model or tool |
| Repair or adaptation | Background removal, decomposition, outpaint, upscale, reframe | The specific utility; do not assume the base model's benefit covers it |

Use the user's selected model when it fits. If it cannot meet a required constraint, explain the specific mismatch before proposing another.

## Inspect the shortlist

For each serious candidate, confirm only the constraints relevant to the brief:

- Real output type: raster, vector, animated image, video, audio, or mesh.
- Reference roles and limits, including whether start/end frames can coexist with other references.
- Supported operation: generation, edit, vectorization, transfer, replacement, or extension.
- Required mode-specific inputs, such as a saved style ID or a driving video.
- Format, transparency, dimensions, duration, and audio controls.
- Coverage and cost for this configuration and execution channel.

Product labels can hide different models or modes. A provider name is not a model ID. A UI product, catalog alias, preset ID, and generation model ID are not interchangeable.

Do not claim that a version is best because a description says so. Treat provider claims as documented positioning and recommendations as task-fit judgments. If comparison is requested, test the same authorized brief under comparable conditions and describe what was actually inspected.

## Reuse versus generation

For a final image or cinematic shot, generation may be the main deliverable. For exact UI demonstrations, legible typography, diagrams, or editable motion, a hybrid workflow may be more reliable: generate the illustrative parts and author precise elements in the target editor or code.

Do not generate a new full image to fix a text label that can be edited directly. Do not force a complex image into SVG merely because vectors scale. Confirm whether the user needs editable parts, just a scalable asset, or a flattened final image.

For repeated outputs, consider approved references and reusable elements before generating unrelated candidates. Evaluate cost per accepted result, including rework, rather than price per attempt alone.
